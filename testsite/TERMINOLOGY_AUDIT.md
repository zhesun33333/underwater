# 术语表逐类审核

本表审核 `core/shared_terminology.py` 中的源信号定义、共享支持词与参考解释生成方式。五项词汇指标的公式不变。词表描述兼容的声学线索，不保证每条经过信道的音频都可观察到这些线索，也不保证穷尽所有合法表达。

| 类别 | 核心描述 | 审核结论与边界 |
|---|---|---|
| CW | 稳定单频、频率不变、窄带 | 符合载频结构；有限时长脉冲或包络不应解释为数学上无限长单频 |
| LFM | 线性频率变化、直线时频轨迹、恒定扫频速率 | 符合定义；上扫/下扫由元数据选择，chirp 与 HFM 共享 |
| HFM | 双曲调频、弯曲轨迹、变化的扫频速率 | 符合定义；nonlinear sweep 是兼容的宽泛词，不是双曲规律的充分证据 |
| 2FSK | 两个离散频率状态、符号级频率切换 | 状态数保留类别区分，frequency switching 与 4FSK 共享 |
| 4FSK | 四个离散频率状态、符号级频率切换 | 状态数准确，multi-level FSK 比四状态更宽泛 |
| BPSK | 两个相位状态、约 180 度相位跳变 | 核心定义合理；通用相位跳变词与 QPSK 共享 |
| QPSK | 四个相位状态、正交相位调制 | 核心定义合理；可以出现 180 度相位跳变，不把该线索当成 BPSK 独占 |
| OFDM | 同时多载波、正交子载波、规则子载波间隔 | 符合调制结构；dense carriers 是宽泛描述，保护带、空载波或信道衰落可能改变可见谱线分布 |
| cargo | 宽带背景、机械线谱、推进相关调制 | 使用共同舰船声学词；实际参考解释由该条元数据生成，不凭 cargo 标签强加固定谱型 |
| cruise | 宽带背景、机械线谱、推进相关调制 | 同上；不预设巡航客船一定比其他类型具有更多线谱 |
| fishing | 宽带背景、机械线谱、推进相关调制 | 同上；不预设渔船固定高频或强调制 |
| warship | 宽带背景、机械线谱、推进相关调制 | 同上；不凭类别认定一定更安静或更规则 |
| underwater_target | 水下目标的线谱和推进/机械调制描述 | 动态解释使用保存的频率、线谱和调制参数；不把静态候选词中的低频、弱调制当成所有样本的必备性质 |

## 共享词的实际含义

`narrowband` 和 `narrowband structure` 按既定设计作为非排他的兼容描述加入所有类别，可能描述整体相对带宽或局部频谱成分。词汇计分不区分这些语境，因此命中它们可以贡献 alignment，但不能证明叶类别正确。舰船类同样共享可观察术语，细粒度区分仍由分类指标衡量。

类名短语（如 cargo vessel）仍按既定实现保留在对应支持集合内。Prompt 要求模型不只复述类名，当前评分器没有额外的类名剔除、否定理解或语义裁判。这些是已明确的词汇诊断边界，不声称完成了自然语言语义验证。

## 元数据驱动的参考解释

LFM/HFM 的方向由 `signal_params.sweep_direction` 决定。舰船线谱范围、线谱数量、轴频/叶频谐波和调制强度来自 `signal_params`。缺失字段时存在较通用的回退描述，因此发布前仍需确认源元数据完整。参考解释是模板生成的源参数描述，不是对接收音频逐条人工确认的可听特征。
