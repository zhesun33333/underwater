# 图 C：同源信号传播前后对比

入口为 `figures/data/channel_examples.py`，输出同目录的 PDF、PNG、溯源 JSON 和完整绘图数据 `.data.json.gz`。图 C 直接使用源音频与已有 Eval 传播 WAV，不需要模型预测，也不重新运行传播仿真。

## 布局与数据

默认三行分别为 LFM、2FSK、游轮，三列为源音频及同一 source ID 的两条真实信道输出。选择这三个类别是为了分别展示扫频、频移键控和舰船谱形，不代表覆盖全部十三类。

每行限定一个类别，在 Eval 中具有两条不同信道输出的源中选样，每个源只有一票。特征为实际 WAV 时长、所选信道质量统计量的均值，以及主动信号的源频率；按候选源内的中位数/IQR 距离选最近者，零 IQR 特征不参与，source ID 打破并列。质量统计量为主动信号 `G_h`、舰船 `S_src`。不按识别正确性、传播差异大小或成图外观挑样。若某行没有双信道源，则所有行统一改为“源＋一条真实信道”的两列布局，不补造第二条输出。

初始配置使用 `raw_data/PulseCom.tar` 和 `raw_data/cruise_ship.tar`。准备阶段按所选 source ID 定向读取 WAV 和同名 JSON/JSONC，拒绝重复成员、链接和不完整配对；当前 JSONC 成员为 JSON 兼容格式，不对非法内容做猜测修复。只缓存选中的源 WAV，不解压完整归档。完整归档用大小/修改时间检测变化，所选成员单独保存 SHA-256；不宣称对数十 GB 归档做了全文件哈希。

同源检查包括源元数据 ID、类别、信号生成参数，以及源与输出 WAV 的单声道、采样率、帧数一致性。源元数据中可能过时的 `audio_duration_s` 不参与时长计算。传播距离、深度、海底和声速剖面取 `_meta.bellhop_env`，保留完整记录，不能采用顶层遗留几何参数。图中显示实际信道 ID 与距离，完整深度和环境参数放在伴随 JSON。

## 归一化与声学分析

- 所有 WAV 均先按同一规则除以各自完整波形的绝对峰值，再截取分析窗口。这样比较结构，不推断传播损失、物理声压或源/接收声级比。每条波形的原始峰值和缩放系数均保存。
- LFM 使用完整 1.5 s 波形（当前选样）；STFT 为 16 ms Hann 窗、2 ms 步长。
- 通信使用源与接收完全相同的中心窗口，最长为 24 个名义符号；单载波 STFT 使用两符号 Hann 窗、1/8 符号步长。若改选 OFDM，复用 A 的 OFDM 窗口与参数检查规则。
- 每个主动信号行共用一个功率参考：该行所有分析窗口、全部频率的最大 STFT 功率。两个主动行的 0 dB 参考各自独立，范围均为 −50 至 0 dB；保留完整计算值。
- 舰船对整条归一化波形计算 Welch PSD，1 s Hann 窗、50% 重叠、常量去趋势、均值平均；显示 0–1000 Hz。三列的频率和纵轴范围相同。PSD 的参考为 `1 / Hz`，对应无量纲归一化振幅的功率密度。
- 接收 WAV 已由传播流程按首次到达对齐；舰船宽带输出采用全频率共同首次到达。绘图不额外平移、不展示绝对传播时延。通信横轴为截取起点之后的毫秒；原始采样区间和绝对到达时延保存在伴随记录。

## 本机运行

在项目根目录，使用主 README 中配置的 `$plotPython`：

```powershell
Copy-Item visualization/channels.example.json visualization/channels.local.json
& $plotPython -m visualization prepare-channels
& $plotPython -m visualization render C
```

基础数据缓存应先用 `python -m visualization prepare` 准备好；本机已有。首次 `prepare-channels` 需要扫描源归档，之后纯布局修改只运行 `render C`。源文件、选样/分析代码或配置变更会要求重新准备。

可用 `--channel-config 路径` 指定 C 配置（放在子命令之前），或设置 `UABENCH_CHANNEL_CONFIG`。源归档和缓存路径相对于 C 配置文件解析。允许在三个家族内更改示例类别，并显式指定相应源归档。

默认宽 180 mm、高 115 mm、Times New Roman 9 pt；基础配置 `style.channel_height_mm` 可覆盖高度。九个面板保留完整轴标题与刻度，以固定物理间距容纳两行面板标题和横轴标签。时频图以至少 300 dpi 栅格嵌入，谱线及文字保持矢量。Tavotto 入口无参、导入无 I/O，`main()` 不写准备缓存或溯源文件。

2026-10-09 将高度由 135 mm 压缩到 115 mm，选样、数据、分析参数与归一化均不变。

当前只进行了独立的数值、文件和版式检查；此前宿主自动拒绝 Tavotto 工作区授权，本图不声称完成 MCP 交互预检。
